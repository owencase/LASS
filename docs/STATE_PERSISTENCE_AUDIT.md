## 범위와 한계

- 브라우저 초안은 같은 브라우저와 주소에서 복구된다. 브라우저 데이터 삭제·다른 기기로의 이동은 복구 범위에 포함되지 않는다.
- 녹음 중 아직 서버로 전달되지 않은 브라우저 메모리의 오디오 큐는 앱 강제 종료 시 복구되지 않는다. 서버가 받은 구간은 작업 파일에 기록하고, 완료한 전사는 DB에 저장한다.
- 실행 중인 생성 작업은 화면 이동·브라우저 연결 종료를 견딘다. 앱 프로세스 자체를 종료하면 작업은 중단되며, 완료된 결과와 저장된 질문·원본·퀴즈 체크포인트는 유지된다.
- PDF 페이지·확대율·패널 열림·레이아웃·업로드 파일 선택 등 표시/선택 상태 전체를 영구 복원하는 기능은 추가하지 않았다. 저장된 사용자 내용과 구분되는 UI 설정이다.

## 검증

- `tests/test_session_persistence.py`: 기존 DB 이관, 세션 분리, 100개 초과 이력, 전사 중복 방지, 인덱스 실패 후 결과 보존, UI 상태 초기화 후 백그라운드 저장 및 수신 확인 순서.
- `tests/test_global_chat.py`: 새 대화 생성 후 기존 세션 재선택과 이력 복원.
- `tests/test_quiz_ui.py`: 화면 이동·새 UI 세션에서 미제출 OMR 및 응시 ID 복원, 제출·재응시.
- `node tests/editor_draft_check.cjs`: 편집 초안의 기준 내용·노트 범위·취소·손상된 저장소 처리, 채팅 초안 복원·세션 분리·제출 후 무효화.
- 실제 브라우저: 사용자 우측 / AI 좌측 말풍선, 하단 입력창, 세션 패널, 새로고침 초안 복원, 세션별 초안 분리 확인.
- 실제 음성 모델과 마이크를 사용하는 장시간 백그라운드 녹음은 이번 테스트에서 실행하지 않았다. 전사 수명주기는 제어 가능한 가짜 전사기로 검증했다.
