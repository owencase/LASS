# 1.3.7 변경 및 검증

화면 구조와 기존 데이터는 유지한다. project2 복원 기반 위에 최신 명세의 출력 형식, 버퍼 처리, OCR 인식 및 자동 백업을 적용했다.

| 항목 | 반영 및 검증 |
|---|---|
| BUG-001 | 업로드 음성 처리를 화면과 독립된 작업으로 실행. 화면 이탈 후 완료·DB 재조회 검사 통과. 기존 라이브 녹음 중복 이벤트 방지와 메모·세션 보존 검사 유지. |
| BUG-002 / FEAT-002 | 독립 패널 열기·닫기, 세션 생성·저장·불러오기·우클릭 삭제·이름 변경 회귀 검사 유지. |
| BUG-003 | 업로드 하위 액션 시 선택 영역을 즉시 비우고 입력 키를 교체. |
| BUG-004 | 기존 원문 기반 출제·독립 정답 검수·모호한 보기/코드 조각 필터 유지. 퀴즈 제출·재응시·기록 검사와 브라우저 좌우 배치 확인. |
| BUG-005 / FEAT-004 | 요약 중간 디스크 파일 제거. 토큰 예산에 맞춘 입력 배칭, 제한된 계층 버퍼, 정확히 일치하는 시스템 접두부의 KV 캐시 복사·재사용. |
| BUG-006 | 요약 패널의 상시 적재 옵션 제거. 요청 성공·실패 후 모델과 작업용 KV 캐시 해제. |
| BUG-007 | 업로드 텍스트·아이콘에 테마 색 적용. 브라우저에서 다크 테마 실제 색 확인. |
| BUG-008 | 네이티브 본문과 공존하는 이미지 영역도 OCR. 단어·행 좌표로 띄어쓰기, 같은 행의 좌우 순서, 코드 들여쓰기 복원. 실제 코드 이미지 및 혼합 PDF 검사 통과. OCR 철자·대소문자의 완전한 일치는 보장하지 않는다. |
| BUG-009 | 지속적인 OCR 실패 배너 제거. 실패는 일회성 알림으로 표시하고 재처리 시작 시 오류 상태 초기화. |
| FEAT-001 | 기존 채팅 피드와 음성 제어 하단 고정 유지. 브라우저에서 긴 전사 및 업로드 영역 열린 상태의 하단 위치 확인. |
| FEAT-003 | 원문 페이지 압축 저장, 필요한 페이지의 동적 해제 및 기존 원문 데이터 호환 유지. LangChain 기반 LLM 스트리밍과 STT 구간 콜백 유지. |
| FEAT-005 | 주제 → 학습 목표 → 개념 → 상세 내용 → 정리 → 중요 포인트 순서 정규화. 누락 항목은 근거 부족 표시. 원문에 없는 정보를 보충하지 않는다. |
| FEAT-007 | 문서/Backups 또는 지정 폴더에 패치·빌드·설치 업데이트 전 ZIP 저장. 실패 시 패치·설치 중단. 앱 업데이트는 데이터 백업도 별도 수행. 향후 에이전트 작업의 사전 백업 규칙을 AGENTS.md에 추가. |

원문은 `source_text_pages`에 보존하고, 요약과 원문 페이지 사이의 참조를 `summary_source_links`에 저장한다. 중간 요약은 원본의 대체 저장소가 아니다. 기존 1.3.5 압축 원문 변환과 과거 원문 조회도 유지한다.

검증: Python 전체 검사 166개, Node 컴포넌트 검사 3개. 실제 CUDA 요약 645자·168개 스트림 조각·입력 3개를 한 번의 모델 호출로 처리했다. KV 재사용 검사에서 캐시 적중과 응답 동일성을 확인했다. 단일 짧은 응답의 측정은 캐시 사용 0.331초, 미사용 0.478초이며 전체 강의의 처리 시간 개선율을 뜻하지 않는다.
