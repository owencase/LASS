# LASS 1.3.5

## 음성 제어 하단 고정

전사 영역과 버튼을 감싸는 Streamlit fragment 래퍼의 Flex 높이를 제한한다. 긴 전사와 업로드 입력창은 상단 내용만 스크롤하며 음성 업로드·녹음·일시정지·정지 제어부는 AI 패널 하단에 유지한다. 영구 녹음 iframe은 이동하거나 새로 만들지 않는다.

## v1.3.0 요약 복원

로컬 `LASS-Setup-1.3.0.exe`에서 설치 없이 추출한 다음 세 파일을 바이트 단위로 복원한다.

- `src/llm/summarizer.py`: 조각별 근거 메모를 임시 JSONL 파일에 저장하고 4개씩 계층 압축한 뒤 최종 요약을 생성한다.
- `src/llm/prompt_manager.py`
- `prompts/lecture_detail.yaml`: 강의 주제와 학습 목표, 핵심 개념, 예시, 핵심 정리, 복습 질문 3개.

1.3.4에서 추가한 소형 GPU의 CPU 분산 배치도 제거하고 v1.3.0처럼 선택한 장치에 모델을 적재한다. 화면 이동 중 작업 유지와 전사 저장, 채팅 세션 기능은 유지한다. 기존 저장 요약은 자동 변경하지 않으며 **다시 요약하기**를 실행하면 복원된 프롬프트가 적용된다.

## 문서 메모리

v1.3.0의 문서 뷰어는 이미 필요한 페이지의 미리보기만 로드했으므로 유지한다. 당시에도 OCR 마지막 단계에는 전체 텍스트를 합치는 경로가 있었으며, 이번에는 새 PDF/PPT 추출에 페이지 이터레이터와 zlib 압축 SQLite 저장을 추가한다. 전체 텍스트를 Python 문자열로 합치지 않는다. OCR 중에는 임시 디스크 DB에 저장하여 메모 쓰기를 막지 않으며 완료한 자료만 원자적으로 공개한다. 요약·검색·시험 생성은 한 페이지씩 압축을 해제해 읽는다. 실패하면 기존 자료와 요약을 보존한다. 기존 평문 저장 자료는 자동 변환하거나 삭제하지 않고 SQLite 부분 읽기로 요약한다. 전체 Markdown 내보내기는 사용자가 요청한 전체 자료를 포함한다.

## 시험 문제 검수

원문 조각에 일치/불일치 문구를 붙이던 O/X 대체 출제 로직을 제거한다. 완결된 개념 근거를 선택해 실제 이해를 평가하는 문항을 생성한다. O/X와 4지선다 모두 출제 정답을 숨긴 독립 검수, 원문 인용 확인, 학습 가치와 정답 유일성 검사를 수행한다. 출제 정답과 검수 정답이 다르거나 근거가 부족하면 저장하지 않고 재출제한다. 예전 미검수 초안과 개념 이력은 새 검수 이력에 재사용하지 않는다. 기존 시험·응시 기록은 삭제하지 않으며, 부적절한 예전 문제는 다시 생성해야 한다.

시험 근거는 원문 녹취·문서 텍스트를 우선 사용한다. 원문이 없으면 직접 작성한 메모를 사용하며 AI 요약은 원문 대신 출제 근거로 사용하지 않는다. 채팅 검색은 기존처럼 원문·요약·메모를 함께 검색한다.

검수는 로컬 모델의 판단을 포함하므로 사람이 검토한 정답표를 대체하지 않는다. 복수 정답·판단 불가·근거 인용 오류는 저장을 차단한다.

기존 앱을 종료하고 `dist/installer/LASS-Setup-1.3.5.exe`로 업데이트한다.

## 검증 결과

- 전체 회귀 테스트 160개와 녹음·편집 초안·문서 뷰어 JavaScript 검증 통과.
- v1.3.0 설치본의 build-info 해시와 복원한 세 파일 일치. 새 번들 소스·리소스 60개와 현재 소스 일치.
- 실제 로컬 모델에서 O/X 모순 판정, 단일 정답 객관식 검수, 생성한 O/X 문제의 재검수 및 복원된 요약 생성 완료. 원문과 다른 검수 인용과 복수 정답 판정은 저장을 차단했다.
- 긴 전사와 업로드 입력창을 열고 닫은 브라우저 검증에서 음성 제어 영역 하단과 패널 하단이 일치함을 확인했다.
- 패키징된 실행 파일의 실제 CUDA 모델 응답과 데스크톱 자체 검사 통과. 설치 파일 ProductVersion 1.3.5와 SHA-256 파일 일치.
