# LASS 1.3.4

요약을 주제·개요·학습 목표·핵심 개념·상세 노트·정리·중요한 점으로 확장한다. 원문의 하위 기술, 절차, 입출력, 함수 이름, 조건과 한계를 설명하도록 요청하며 1,500자 압축 제한을 제거한다.

자료를 실제 토큰 수에 맞춰 묶고, 상세 설명과 안내 항목을 분리해 생성한다. 이전 요약을 매번 다시 압축하는 방식 대신 생성된 설명을 항목별로 조립한다. 상세 설명부터 백그라운드 스트리밍으로 표시한다. 필수 항목 보완 시 누락된 항목만 요청하고 기존 설명을 보존한다. 실패하면 기존 저장 요약을 유지한다.

요약은 결정적 생성 방식을 사용한다. 6GB 이하 GPU는 가중치 배치에 메모리 한도를 두어 생성용 캐시와 데스크톱 사용 공간을 확보하고 필요한 가중치는 CPU로 분산한다. 큰 GPU와 CPU 전용 실행은 기존 배치를 사용한다. 로컬 모델의 처리 속도와 사실 정확도는 자료와 하드웨어에 따라 달라지며 생성 내용은 원문 대조가 필요하다.

`dist/installer/LASS-Setup-1.3.4.exe`로 업데이트한다. 설치 후 새 버전에서 기존 노트의 **다시 요약하기**를 실행하면 새 형식으로 생성된다. 기존 저장 요약을 자동으로 변경하지 않는다.

## 검증

- 전체 회귀 테스트 160개 통과. 입력 용량 초과 분할, 앞·중간·끝 원문 보존, 상세 설명 유지, 누락 항목만 보완, 한국어 조사에 붙은 API 이름 보충을 확인했다.
- 번들 소스·리소스 60개와 현재 소스의 SHA-256 일치. 패키징된 실행 파일에서 실제 모델 응답 및 CUDA 자체 검사 통과(PyTorch 2.7.1+cu118, CUDA 11.8, RTX 3050 Ti Laptop GPU).
- 1,514자 강의 예시에서 2,146자 요약 생성 완료. 검사한 기술 용어 11개를 모두 포함했다. 첫 출력 16.8초, 전체 173.3초. 이전 방식은 같은 자료에서 필수 항목 검증에 실패했으므로 전체 처리 시간의 감소율을 산출하지 않았다. 총 지연의 대폭 감소는 검증되지 않았다.
