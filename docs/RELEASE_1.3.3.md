# LASS 1.3.3

이전 작업의 오류 수정과 기능 변경을 모두 포함해 Windows 실행 파일 및 설치 프로그램을 새 버전으로 빌드한다. 앱 버전, 패키지 버전, 설치 프로그램 버전을 1.3.3으로 일치시킨다.

패널 열기·닫기 분리, 대화 세션 이름 변경·삭제, 음성 업로드 선택 초기화, 퀴즈 렌더링 수정, LangChain 응답 스트리밍과 구조화된 합성 요약을 포함한다. 자세한 변경 내용은 [이전 변경 명세](RELEASE_1.3.2.md)를 참고한다.

## 설치

`dist/installer/LASS-Setup-1.3.3.exe`를 실행하여 기존 설치를 업데이트한다. 기존 앱을 종료하고 설치해야 설치된 앱에 변경사항이 적용된다. 사용자 데이터·모델 저장 경로와 기존 AppId를 유지한다.

## 검증

- 업데이트·배포·데스크톱 관련 테스트 13개 통과.
- 번들 소스·리소스 60개와 현재 소스의 해시 일치 및 앱 버전 1.3.3 확인.
- 새 EXE 자체 검사 종료 코드 0. PyTorch 2.7.1 / CUDA 11.8 / RTX 3050 Ti에서 CUDA 연산 확인.
