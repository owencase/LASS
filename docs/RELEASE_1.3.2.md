# LASS 1.3.2

## 변경 사항

- STT 완료 결과를 검색 인덱스 정리보다 먼저 저장하고, 실시간 전사를 백그라운드에서 처리한다. 저장 완료 후 녹음 이벤트를 확인 처리하고 재전송된 구간의 중복 저장을 방지한다.
- 재접속 시 선택한 노트를 복원하고 메모·채팅·요약·녹취 편집 초안을 보관한다. 미제출 퀴즈 OMR 답안과 응시 정보를 저장·복원한다.
- 채팅을 사용자 우측 / AI 좌측 말풍선과 하단 입력창으로 구성한다. 생성 중 상태를 표시하고 기존 PDF 뷰어의 색상·서체·컴포넌트 스타일을 공유한다.
- 좌측 상단 버튼으로 대화 목록 패널을 열고 새 대화를 생성하거나 저장한 세션을 다시 연다. 새 대화는 기존 기록을 삭제하지 않는다. 우측 상단 아이콘으로 노트 화면에 복귀한다.

## 추가 요구 반영 빌드

- 채팅 패널 열기와 닫기를 독립된 아이콘으로 분리하고, 고정 헤더와 목록 스크롤을 적용했다. 기존 노트 목록의 컨텍스트 메뉴를 공유하여 세션 이름 변경·삭제를 지원한다. 삭제된 세션은 재실행 시 복구되지 않으며 다른 세션 기록은 유지한다.
- 음성 파일의 하위 업로드 액션으로 원본 등록이 완료되면 선택 영역을 닫고 입력 키를 갱신하여 같은 파일이 남아 중복 추가되는 문제를 해결했다.
- 퀴즈 본문이 좌측 패널 뒤로 가려지는 배치를 수정하고, 보기 번호를 일반 텍스트로 표시했다. 저장된 시험의 스키마를 재검증하여 손상된 시험은 오류와 재생성 안내를 표시한다. 손상된 과거 문항은 재생성을 방해하지 않는다.
- LLM 공통 호출에 LangChain 프롬프트·대화 이력·모델·문자열 파서 체인을 적용했다. 채팅과 최종 요약을 토큰 단위로 표시하고 STT는 인식 구간 콜백을 표시한다. 음성 인식 중 단어 수준의 가설 전사는 제공하지 않는다.
- 발췌 문장 선택 대신 주제·개요·핵심 개념·상세 노트 형식의 합성 요약본을 생성한다. 긴 자료는 원문 조각을 순서대로 통합하고 마지막 통합본을 스트리밍한다. 필수 항목 누락 시 한 번 보완하며 보완 실패 시 기존 저장 결과를 유지한다. 합성 내용의 사실 정확성은 모델 품질과 원문에 영향을 받는다.

## 검증

- Python 회귀 테스트 154개 통과. 세션 삭제·이름 변경, 업로드 선택 초기화, 잘못된 퀴즈 복구, 체인의 역할·토큰 전달, 요약 형식 보완을 포함한다.
- 편집 초안 및 녹음 컨트롤 JavaScript 검증과 목록 컴포넌트 문법 검사 통과.
- 23초 테스트 음성에서 STT 인식 구간 콜백 2회와 완료 전 표시를 확인했다.
- EXE 자체 검사 통과. 번들 소스·리소스 60개가 현재 소스와 일치하며 PyTorch 2.7.1 / CUDA 11.8 / RTX 3050 Ti 환경에서 CUDA 연산을 확인했다.
- 로컬 EXAONE CUDA 모델에서 한국어 합성 요약과 완료 전 토큰 표시를 검증했다. 첫 토큰 약 13초, 형식 보완 포함 약 39초로 처리했다. 이는 짧은 테스트 자료 한 건의 측정값이다.
- 별도 DB를 사용하는 브라우저에서 퀴즈 좌우 배치, OMR, 대화 패널 열기·닫기 및 우클릭 이름 변경을 확인했다.

## 설치와 실행

`dist/installer/LASS-Setup-1.3.2.exe`를 실행하여 기존 설치를 업데이트한다. 설치된 앱은 설치 프로그램으로 교체해야 최신 변경이 적용된다. 프로젝트의 `LASS.bat` 또는 `dist/LASS.exe`는 새로 빌드한 개발용 배포본을 실행한다.

기존 AppId와 사용자 데이터·모델 저장 경로를 유지한다. 이번 작업은 로컬 설치 파일 생성이며 GitHub Release 게시나 사용자 설치본 교체는 포함하지 않는다.

상태 보존 조사와 검증 범위는 [STATE_PERSISTENCE_AUDIT.md](STATE_PERSISTENCE_AUDIT.md)를 참고한다.
